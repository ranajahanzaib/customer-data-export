# Changelog

Notable changes are recorded here. This project has not published a versioned release.

## Unreleased

### Added

- Tenant-scoped export API, PostgreSQL job queue, and lease-based worker.
- Repeatable-read dataset collection for the example SaaS schema.
- Attachment retrieval with ownership, size, optional object-version, and SHA-256 checks.
- ZIP/JSONL export format, integrity manifest, and offline verifier.
- S3-compatible artifact storage, short-lived download URLs, and expiration cleanup.
- Local PostgreSQL and MinIO Compose environment, administrator dashboard, CLI, and integration-test suite.
